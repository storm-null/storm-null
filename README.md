## `01` / ABOUT ME

```text
USER       : Storm-Null
DOMAIN     : Cybersecurity & Systems
ENVIRONMENT: Linux / Windows
INTERESTS  : Security Research, RE, Low-Level Development
PHILOSOPHY : Learn deeply. Test safely. Document everything.
```

I'm a cybersecurity enthusiast with a strong interest in Linux, system administration, reverse engineering and low-level software. I enjoy figuring out how things work beneath the surface: from services and permissions to processes, binaries and operating-system behaviour.

My goal is to build solid fundamentals, learn through hands-on labs, and turn discoveries into useful projects and documentation.

> [!TIP]
> **Infrastructure explains how systems are built. Security research helps us understand how they behave — and how to make them stronger.**
